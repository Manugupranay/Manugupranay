## 🏥 MedAssist AI — Featured Project

> **The most transparent clinical AI system I have ever built. Every decision is fully auditable.**

```
User input (clinical description)
        ↓
[Plan node]      Claude analyzes vitals and symptoms
        ↓
[Risk score]     GBM model trained on NEWS2 protocol  →  HIGH 85%
        ↓
[RAG search]     WHO/NHS protocols retrieved in 0.003s
        ↓
[Synthesize]     Claude generates cited clinical recommendation
        ↓
[Critic node]    Self-corrects if output is incomplete or inconsistent
        ↓
[SOAP + MCP]     Auto-generates SOAP note + books follow-up via Google Calendar

Full audit trail:  💰 $0.046  |  ⏱️ 34s  |  🔢 6 nodes  |  Fully traceable
```

**Plus Multi-Agent System (Angle 3):**
```
3 specialist agents run IN PARALLEL
🩺 Diagnosis  +  💊 Pharmacy  +  📋 Care Plan
        ↓
🤝 Consensus Generator resolves conflicts → unified recommendation
```

🔗 **Live:** [pranay-medassist.netlify.app](https://pranay-medassist.netlify.app)
